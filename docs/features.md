## v0.1 功能范围（更新于 2026/8/21）

- 记录收入
- 记录支出
- 分类
- 历史流水
- 月总预算
- 分类预算
- Dashboard
- 每日可用预算
- 本地数据库

## v0.1 暂不包含

- 云同步与多设备同步
- 登录
- AI 分析
- OCR
- 银行账单导入

## v0.2 功能范围（更新于 2026/8/21）

- 完整数据 JSON 导入与导出（流水、分类、预算）
- 流水 CSV 导入与导出，保留无损的最小货币单位
- 本地备份文件创建与原子恢复
- 流水按月份、分类、账户、收入/支出筛选
- 按备注关键词搜索流水
- Dashboard 最近 6 个月支出趋势
- Dashboard 分类消费排行
- Dashboard 最近 7/30 天消费趋势
- 预算可管理本月与紧邻的下个月，不提前创建更远月份
- 流水页不进入未来月份，新增流水不允许选择今天之后的日期
- 短时长、可中断的原生动画和主线程外文件编解码

## v0.2 数据文件约定

- 普通 JSON/CSV 导入按 ID 合并，不删除未涉及的本机数据。
- 备份恢复会在用户二次确认后完整替换本机数据，并在单个数据库事务中执行。
- JSON 使用带 `schema_version` 的 FinanceOS 格式，便于后续兼容升级。
- CSV 使用 UTF-8，并用 `amount_minor` 作为再次导入时的精确金额来源。
